----------------------------------------------------
نصب و اجرا
----------------------------------------------------

1️⃣ کلون کردن پروژه:

git clone <REPOSITORY_URL>


----------------------------------------------------

2️⃣ ورود به مسیر پروژه:

cd <PROJECT_FOLDER_NAME>


----------------------------------------------------

3️⃣ نصب وابستگی‌ها:

npm install


----------------------------------------------------

4️⃣ اجرای پروژه در حالت توسعه:

npm run dev


----------------------------------------------------

5️⃣ مشاهده پروژه در مرورگر:

http://localhost:5173/
