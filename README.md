====================================================
 نصب و اجرا
====================================================

1️⃣ کلون کردن پروژه:

git clone <REPOSITORY_URL>

----------------------------------------------------

2️⃣ ورود به مسیر پروژه:

cd <PROJECT_FOLDER_NAME>

----------------------------------------------------

3️⃣ اجرای تنظیمات اولیه (Setup):

npm run setup

📌 این دستور موارد مورد نیاز پروژه (مثل فونت‌ها) را آماده‌سازی می‌کند.

----------------------------------------------------

4️⃣ نصب وابستگی‌ها:

npm install

----------------------------------------------------

5️⃣ اجرای پروژه در حالت توسعه:

npm run dev

----------------------------------------------------

6️⃣ مشاهده پروژه در مرورگر:

پس از اجرای پروژه، مرورگر خود را باز کرده و به آدرس زیر بروید:

http://localhost:5173/
